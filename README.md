# 售后服务工作台

## 启动

在项目目录运行：

```sh
python3 server.py
```

然后打开 <http://127.0.0.1:8765>。首次打开会引导创建唯一的超级管理员账号；之后使用该账号登录。服务默认只监听本机地址。

## 当前框架

- 单一超级管理员登录，不设置员工账号或权限分级。
- 服务记录存入项目目录的 `data/ass.db` SQLite 数据库。
- 支持上门送货、上门维护、远程服务、驻场服务和大型项目记录。
- 支持成员、类型、周期、状态统计，记录筛选和 CSV 导出。
- 成员预置为陈巨鹏、肖林、洪凯。

数据库文件和本地环境文件不会提交到 GitHub。
